# UI Figures (Screenshots) for Chapter 4

This folder is intended for final thesis screenshots (PNG/SVG) referenced in Chapter 4.

Recommended naming (consistent with thesis numbering):
- `fig_4_3_home.png`
- `fig_4_4_strategy_builder.png`
- `fig_4_5_backtesting_workspace.png`
- `fig_4_6_strategy_lab_comparison.png`
- `fig_4_7_assistant_grounded_response.png` (optional)

Capture guidelines:
- Use a consistent viewport (for example 1440x900 or 1536x864) and crop out irrelevant browser chrome.
- Prefer light theme unless your thesis formatting expects dark backgrounds.
- When possible, include the assumptions/diagnostics panels in the same frame as the numeric outputs.
- Avoid including secrets, access tokens, or personal identifiers.
