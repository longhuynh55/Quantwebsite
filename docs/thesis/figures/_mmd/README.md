# Extracted Mermaid Sources (.mmd)

This folder is generated by `pnpm run thesis:figures:export`.

Each `.mmd` file is extracted from the first Mermaid code block in `docs/thesis/figures/*.md` and can be:
- Previewed in VS Code Mermaid preview extensions
- Pasted into Mermaid Live for export
- Rendered via Mermaid CLI (`mmdc`) by re-running the export script
